# MCP server for tällmi: research (October 2026)

## Specification

- **Current version: 2026-07-28.** The two before it were 2025-11-25 and 2025-06-18. Sources: https://modelcontextprotocol.io/specification/versioning and the changelog at https://modelcontextprotocol.io/specification/2026-07-28/changelog
- **Transports:** stdio and **Streamable HTTP**. The old HTTP+SSE transport is deprecated.
- **What 2026-07-28 changes:**
  - It is **stateless**: no `initialize` handshake and no session ID.
  - New `server/discover` method.
  - New required headers: `MCP-Protocol-Version`, `Mcp-Method`, `Mcp-Name`.
  - Structured tool output uses JSON Schema 2020-12.
- **Security rules for local servers** (https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http):
  - The server **MUST** validate `Origin` (DNS-rebinding protection).
  - It **SHOULD** bind to 127.0.0.1.
  - It **SHOULD** authenticate.
  - Authorization (OAuth 2.1) is **optional**. Nothing requires OAuth on localhost.

## Swift SDK

- **Official SDK:** `modelcontextprotocol/swift-sdk` 0.12.1 (May 2026). It requires Swift 6 and macOS 13+.
- **Server transports included:** `StdioTransport`, `StatelessHTTPServerTransport`, `StatefulHTTPServerTransport`.
  - They are framework-agnostic: they take a request and return a response, so you supply the HTTP listener yourself.
  - They come with `OriginValidator.localhost()` and bearer-validation hooks.
- **Limitation:** the SDK targets spec 2025-11-25. Clients mostly speak that today. Add 2026-07-28 once the SDK supports it.
- **Listener options:** the lightest is Network.framework (`NWListener` on 127.0.0.1). Hummingbird is the step up if needed.

| Jan, goose | not documented | yes | yes | via a stdio helper |
| Ollama | — | — | — | **not an MCP client**; needs a front-end |

There is no client called "MCP Lite"; the name belongs to server-building libraries. The client the owner used was most likely LM Studio.

## Recommendation (adopted pending owner confirmation)

- **Transport:** Streamable HTTP inside the app, on `127.0.0.1:<port>/mcp`.
  - Use the official swift-sdk with the stateless transport, on an `NWListener`.
  - Later, add a tiny bundled **stdio helper** that relays to the app, for Claude Desktop, Jan and goose.
- **Auth:** one random **bearer token per client**.
  - Tokens live in the Keychain. Each token maps to the client's config row (granted tools and limits).
  - Origin allowlist, bind to 127.0.0.1, and revocation.
  - No OAuth.
- **Entitlement:** `com.apple.security.network.server` (incoming connections only).
  - Outgoing network stays forbidden.
  - This needs an ADR amending ADR 0001 / AGENTS.md rule 1.
- **Write tool:** annotated `destructiveHint`, off by default per client, optionally confirmed in the app.
